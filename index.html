install

Installed in about 90 seconds.

One ZIP, three doors. The two Claude doors are the smoothest-paved — but any AI that runs skills can walk in.

Claude.ai · Desktop · Cowork

  1. Open Settings → Capabilities → Skills
  2. Upload skill → pick your squirrel-*.zip (free or full — same doors)
  3. Toggle it on. Say “squirrel that.”

Upload the ZIP as-is — it keeps the squirrel/ folder at the root, which is what Claude expects. (A loose SKILL.md won't register. We zipped it right so you never think about it.)

Claude Code

terminal
# the folder lands in ~/.claude/skills
unzip squirrel-free.zip -d ~/.claude/skills/
any session
/squirrel

That's the whole install. From then on, /squirrel — or just saying it — runs the capture.

Everywhere else

  1. Skills-capable agent? Agent Skills began at Anthropic in October 2025 and is now an open standard adopted across major AI platforms — point yours at the unzipped squirrel/ folder.
  2. Any capable AI at all? Open SKILL.md and paste it in as instructions. It's plain markdown — any AI that reads can follow it.
